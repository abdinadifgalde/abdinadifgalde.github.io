IUT Appointment Management System

// built together with my brother

A university appointment management system that replaces queues and paperwork with digital scheduling, verification, notifications, and admin workflows.

Built to close the gap between students and university offices — fewer scheduling conflicts, fewer lost forms, one structured platform instead of five ad-hoc ones. Deployed and running in production on Render.

The app follows an MVC structure end to end: JavaFX/FXML screens stay purely presentational, Hibernate/JPA maps domain objects onto a PostgreSQL schema, and a service layer in between handles appointment validation, conflict checks and admin approval logic so the persistence model can change without touching the UI.
