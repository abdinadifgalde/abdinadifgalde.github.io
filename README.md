## About

This repository hosts the source code for my personal portfolio — a single-page site presenting my background, skills, and projects as a Computer Science student. It's built from scratch with vanilla HTML, CSS, and JavaScript, featuring a custom 3D layered visual (interface → logic → data) that reflects how I approach building software.

## Features

- **Responsive, single-page layout** — About, Skills, Projects, Education, Languages, Achievements, and Contact sections
- **Custom 3D interactive stack visual** representing a full-stack architecture
- **Dark/light theme toggle**
- **Scroll-based reveal animations**
- **Downloadable CV**
- Deployed via **GitHub Pages**

## Tech Stack

| Layer | Tools |
|---|---|
| Markup & Styling | HTML5, CSS3 (custom properties, no framework) |
| Interactivity | Vanilla JavaScript |

## Running Locally

No build step required — it's a static site.

```bash
git clone https://github.com/abdinadifgalde/abdinadifgalde.github.io.git
cd abdinadifgalde.github.io
```

Then just open `index.html` in your browser, or serve it locally:

```bash
python3 -m http.server 8000
```

Visit `http://localhost:8000`.
